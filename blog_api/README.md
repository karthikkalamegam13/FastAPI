# Blog API

This project implements a simple blog API using **FastAPI**,
illustrated for a YouTube tutorial. It demonstrates how to
structure a FastAPI application, perform CRUD operations on posts,
add comments, and interact with a SQLite database via
**SQLAlchemy**.

## Features

- **Create, read, update and delete blog posts**
- **Create and read comments on posts**
- **Pydantic models** for request/response validation
- **SQLite** database configured via SQLAlchemy
- Modular **router** organization
- Ready to run with **Uvicorn**

## Getting Started

### Prerequisites

You'll need Python 3.8 or newer. Install the dependencies using `pip`:

```bash
pip install fastapi uvicorn sqlalchemy pydantic
```

### Running the Server

From the repository root (where this `README.md` resides), run:

```bash
uvicorn blog_api.main:app --reload
```

Navigate to `http://127.0.0.1:8000/docs` in your browser to explore
the interactive API documentation generated by FastAPI.

### Directory Structure

```
blog_api/
├── __init__.py         # Package initializer
├── database.py         # Database engine and session management
├── main.py             # Application entry point
├── models.py           # SQLAlchemy ORM models
├── routers/
│   ├── __init__.py     # Aggregates routers
│   ├── comments.py     # Endpoints for comment operations
│   └── posts.py        # Endpoints for post operations
└── schemas.py          # Pydantic models for validation
```

## Notes

This example uses `Base.metadata.create_all()` at import time to
simplify the setup for demonstration purposes. For production
applications you should use a migration tool like **Alembic** to
manage database schema changes.
